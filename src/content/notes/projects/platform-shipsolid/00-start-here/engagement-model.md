## Purpose

How teams engage the platform team — intake, support tiers, and SLAs.

## Engagement modes

| Mode         | When                                                 | Channel               |
| ------------ | ---------------------------------------------------- | --------------------- |
| Self-service | Standard onboarding, config changes                  | Paved-road docs + PR  |
| Consult      | New signal types, custom dashboards, SLO design      | Office hours          |
| Co-build     | Net-new workload class (e.g., streaming, synthetics) | Scoped engagement     |
| Incident     | Platform-impacting outage                            | Grafana IRM / on-call |
