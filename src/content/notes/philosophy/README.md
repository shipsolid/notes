## Philosophy

> If this were a book, this page is the table of contents. Each Part below is a chapter; each
> chapter links out to the concepts and templates that already exist elsewhere in this wiki instead
> of duplicating them. Unwritten chapters are listed as **Planned** rows, not empty files.

## Parts

### 00 — Cognitive Biases & Decision-Making

Judgment errors that recur in engineering and career decisions, and the frameworks that correct for
them. See [[04-decision-journal-template|Decision Journal Template]] for the practical exercise
version of this Part.

- [[01-sunk-cost-fallacy|1 — Sunk Cost Fallacy]] — escalation of commitment, loss aversion, and the
  marginal-cost reframe that fixes it
- Cognitive Biases Catalog — _(planned)_ — Baader-Meinhof / frequency illusion, spotlight effect,
  anchoring, confirmation bias
- Decision Frameworks — _(planned)_ — optimal stopping (37% rule), regret minimization, satisficing,
  Bayesian updating

### 01 — Mental Models & Systems Thinking

_(Planned)_ First-principles reasoning, second-order effects, and antifragility — the general
thinking tools this wiki's technical chapters (see
[[02-tail-latency|Observability's Core Mental Models]] for a domain-specific example) each apply to
a narrower problem.

### 02 — Stoic Practice

_(Planned)_ Dichotomy of control, premeditation of adversity, and virtue-based resilience. See
[[04-2-stoic-journal-template|Stoic Journal Template]] for the daily practice version of this Part.
